# Security policy

This is a portfolio demo, not a supported product, but reports are welcome.

Please report vulnerabilities privately through GitHub's
["Report a vulnerability"](https://github.com/phuong-le-tech/rag-pipeline/security/advisories/new)
form rather than a public issue. Expect a reply within a week.

In scope: the FastAPI service (`src/rag/api/`), upload handling, and the web UI. The guards
(rate limit, daily budget, concurrency cap) and their limits are described in the README under
"Security and privacy".
